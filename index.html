從產業現場到 AI 自動化

我在水產產業工作，熟悉採購、進出貨與品質把關這類每天重複的流程，所以特別在意「哪些事可以交給系統」。

工作之餘，我用 n8n 把 LINE、Telegram 與 Google Sheets 串起來：記帳、補貨通知、版本與匯率推播，都是實際在使用、定時在跑的流程；也會做一頁式網站，把成果清楚呈現給使用者。

流程自動化

從觸發、取得資料、處理，到通知與寫入，能完整串成一條流程。

資料處理與除錯

用 JavaScript (Code Node) 與 Regex 整理 JSON 資料；測試時遇到問題，能找出原因並修正。

異常情境設計

沒有資料、指令無法辨識時，流程也有對應回覆，不會中斷或誤動作。

產業現場經驗

了解實體產業的流程痛點，知道哪些自動化真的用得上。
