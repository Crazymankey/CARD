# CARD 專案網頁檔案說明

這個 Repository 包含兩個獨立的服務網頁：

## 1. `index.html`（公開作品門面）
* **預設網址**：https://crazymankey.github.io/CARD/
* **用途**：放在社群、個人簡介的公開門面，展示四大商業模組，引導潛在客戶私訊詢問。

## 2. `pricing.html`（秘密服務報價單）
* **專屬網址**：https://crazymankey.github.io/CARD/pricing.html
* **用途**：私訊專用報價單！當客戶問「請問怎麼算／多少錢」時，複製此連結傳給客戶使用。
