託管模式 vs 一次性買斷權責比較

比較項目 託管訂閱模式 (AaaS) 一次性專案買斷
伺服器主機與維護 由我們專責維護 (24h 運轉與備份) 移交至客戶端 VPS 主機，由客戶自理
程式碼與智慧財產權 提供託管使用權（無授權釋出 JSON） 完整交付 n8n JSON 原始檔與備份檔
API 變更與斷線修復 包妥於月費中，無額外修復費用 保固期過後，按次排查 (NT$ 1,500 ~ 3,000/次)
免費微調額度 標準版以上每月享 1~2 次免費微調 僅提供移交保固期內除錯 (7~14天)
資金門檻 首期負擔低 ($3,999 起) 一次性投入高 ($12,000 起)
⚠️ 一次性買斷注意事項與商業規範
  • • 伺服器環境自備：買斷客戶需自行支付雲端 VPS 費用（如 DigitalOcean / AWS），或授權由我們代建主機（主機租金按月向雲端廠商支付）。
  • • 單一企業授權：買斷交付之工作流 JSON 檔僅限本合約指定企業/門市使用，未經授權不得轉售、複製或對外商業化。
  • • 保固與售後排查：買斷專案交付後提供 7~14 天系統穩定保固。保固期滿後，若因第三方 API 格式更動或客戶操作不當造成停擺，維護排查費用為 NT$ 1,500 ~ 3,000 / 次。
